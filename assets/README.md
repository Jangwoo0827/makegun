# Assets

The game runs with **no asset files**: everything is drawn with pygame shapes and sounds are synthesized.

## Images (optional)
If `assets/images/<category>/<name>.png` exists, the game draws it instead of the shape.

| Folder | Name | Drawn size | Notes |
|---|---|---|---|
| `enemies/` | enemy id from `data/enemies.json` (`normal`, `boss`, `broodmother`, ...) | ~2.4x radius | **face right**, the game rotates it |
| `player/` | `player` | 40x40 | **face right** |
| `gun/` | receiver / barrel / magazine part id | 8x its slot (see `placeholders/manifest.json`) | **in-game gun piece**, side view, muzzle to the right. Receiver art = body on top + grip at lower-left, rest transparent |
| `parts/` | any part id from `data/weapons.json` (`smg_receiver`, ...) | 96x48 | icon in editor and shop (falls back to the `gun/` image) |
| `pickups/` | `money`, `health`, `ammo`, `buff`, `part` | 32x32 | |
| `tiles/` | `<stage_id>_floor` (160x160) / `<stage_id>_wall` (80x80), or shared `floor` / `wall` | | seamless; generated by `python tools/make_tiles.py`, replace with your own art of the same name |

**Placeholders:** `assets/placeholders/` has a labeled template with the exact file name and size for
every image (see `manifest.json`). Copy one into the matching `assets/images/` folder and paint over it.
After adding new enemies or parts, run `python tools/make_placeholders.py` to regenerate the templates.

## Sounds & music
All sound effects (`assets/sounds/`) and the music loops (`assets/music/menu|battle|boss.wav`) are original and
generated by `python tools/make_audio.py` (pure Python synthesis). Edit that script and re-run to change them,
or replace any WAV with your own file of the same name. Effect names:
`shoot, hit, enemy_die, explosion, pickup, hurt, reload, click, buy, wave, boss` (e.g. `assets/sounds/shoot.wav`).
