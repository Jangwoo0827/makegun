# Changelog

The in-game PATCH NOTES screen reads `data/patch_notes.json`; keep both in sync.
The version shown in game is `settings.VERSION`.

## v1.2.0 — 2026-10-03
- 3 new stages: WASTELAND, THE SPIRE, OMEGA (8 stages total)
- Ascension 1–10: clear the final stage to unlock harder runs with bigger core rewards
- New modes: ENDLESS (infinite waves, rotating bosses) and BOSS RUSH (4 bosses, timed) — unlocked by clearing THE CORE
- 6 playable characters (Gunner, Scout, Demolitionist, Juggernaut, Duelist, Engineer), unlocked with cores in LOADOUT
- New part slot ATTACHMENT: Bayonet, Katana (cuts bullets), Grenade Launcher, Flamethrower, Support Drone, Tesla Coil
- Weapon evolution: get a synergy weapon to Lv.8 and EVOLVE it in the shop (15 evolutions)
- 3 new synergies, 7 new achievements, version number and patch notes screen
- GitHub Actions builds the exe and web zip on every push; tags create a release

## v1.1.0 — 2026-10-03
- Web / mobile build (pygbag) with touch controls
- Device selection on first launch (PC / MOBILE)
- Saves kept in the browser's local storage

## v1.0.0 — 2026-10-02
- 5 stages, meta progression (cores + permanent upgrades), 4 bosses, elite affixes
- Part synergies, dash and grenade, achievements and stats, weapon presets
- Balance caps, save/continue, Windows exe build
